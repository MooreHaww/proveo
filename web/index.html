    About

    Eco mode for AI coding: let the tests choose the model, cheapest first.

    Works for tasks with tests. Each answer is checked against the task's tests; the first rung whose answer passes wins, and more expensive rungs are never called.

    How it works

    1. Verified memory: an exact repeat of a task reuses a stored answer, re-checked against the tests.
    2. Local rungs, in your order: for example a Raspberry Pi 5, then a PC with a GPU.
    3. The cloud rung last, only if every local answer failed, and only while the monthly budget allows.

    Honest limits

    • The measured numbers come from small benchmark coding tasks, one run each.
    • The Pi's answers vary between runs; a failed answer is caught by the tests and escalated.
    • The code check runs in a subprocess with a time limit. It is not a real sandbox.
    • It only helps when a task has tests. Tests that miss a case let a wrong answer pass.
    • Savings figures are estimates or projections unless labelled as measured.
    • The OpenAI-compatible cloud provider is untested.
